# Milestone 3 — Local AI Outreach Drafting & Review

## Objective

Turn a qualified lead into a short, personalized outreach draft using a local Ollama model, persist the draft in SQLite, and require human review before any delivery.

## Scope

- Local Ollama integration through HTTP.
- Default model: `qwen2.5:0.5b-instruct-q4_K_M`.
- Configurable model and Ollama endpoint.
- Generate drafts only for qualified leads.
- Use company, contact, role, pain point, qualification reasons, and relevant lead data.
- Maximum three sentences.
- Professional, concise, specific, and non-spammy copy.
- Validate generated output before persistence.
- Persist prompt/model metadata and generated text for auditability.
- Human review workflow: `GENERATED` → `APPROVED` or `REJECTED`.
- No WhatsApp API, browser automation, or automatic sending in M3.

## CLI

```text
python3 lead_cli.py generate
python3 lead_cli.py generate --priority high
python3 lead_cli.py drafts
python3 lead_cli.py draft <id>
python3 lead_cli.py approve <id>
python3 lead_cli.py reject <id>
```

## Draft validation

A valid draft must:

1. Contain non-empty text.
2. Contain no more than three sentences.
3. Contain no unresolved placeholders such as `{company}`, `[name]`, or `<company>`.
4. Be associated with an existing lead.
5. Be generated by the configured local model.

Generation failures must not create an approved or sent record.

## Data model

Add an `outreach_drafts` table with at least:

- `id`
- `lead_id`
- `status`
- `message`
- `model`
- `prompt`
- `validation_error`
- `created_at`
- `reviewed_at`

Recommended statuses:

```text
GENERATED
APPROVED
REJECTED
```

## Safety boundary

M3 is a drafting and review milestone. Approval does not send a message. Delivery is explicitly deferred to a later milestone.

## Test strategy

Tests must use a mocked/local fake Ollama response rather than requiring Ollama to be running. Cover successful generation, validation, persistence, missing/failed Ollama responses, three-sentence limit, placeholder rejection, approval, rejection, and protection against sending side effects.
